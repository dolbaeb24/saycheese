# Рендер, проверка, выдача

Все команды рендера запускаются из `$LIB` (папка lemo-opuscar) с абсолютным путём к проекту `$P`. Каждый инструмент принимает `--size 1080x1920`, без этого кадр будет горизонтальным.

## Контракт страницы

`index.html` проекта загружает шрифты и выставляет:

```js
window.DUR = 79.4;              // длина в секундах
window.EV = [{t, k, d?, v?}];   // звуковые события для mix.py
window.CUES = [[t0, t1, text]]; // субтитры (их же рисует страница)
window.render = t => {...};     // рисует кадр в момент t; детерминированно
window.READY = true;            // только после document.fonts.load(...)
```

Детерминированность обязательна: никаких `Math.random()` без сида (используй `hash(i)`), `Date.now()` и состояния между кадрами. Любой кадр должен рисоваться сам по себе, в любом порядке.

## Команды

```sh
cd "$LIB"
# стоп-кадры (0.1-0.3 с на кадр) -> $P/stills/<prefix><t>.jpg
node core/render/still.mjs "$P" 1.5 4.6 8.2 12.3 16.8 22.3 27.5 --size 1080x1920 --out "$P/stills" --prefix a_
# лист с красной рамкой безопасной зоны (каждый раз новое имя файла)
.venv/bin/python <workspace>/.agents/skills/reel-render-qa/scripts/safe_sheet.py "$P/stills/sheetA.jpg" "$P"/stills/a_*.jpg
# полная сборка: события -> видео -> микс -> мастеринг -> srt
sh "$P/build.sh" > "$P/build.log" 2>&1; echo "EXIT $?" >> "$P/build.log"
```

`build.sh` проекта делает по порядку:

```sh
node "$LIB/core/render/events.mjs" "$P" --size 1080x1920 --out "$P/events.json"
node "$LIB/core/render/video.mjs" "$P" --fps 24 --size 1080x1920 --workers 3 --out "$P/out/video.mp4"
"$LIB/.venv/bin/python" mix.py                                   # -> mix.wav длиной DUR + 8 с
sh "$LIB/core/render/mux.sh" out/video.mp4 mix.wav out/<name>.mp4 24 0   # -14 LUFS, зерно 0
"$LIB/.venv/bin/python" "$LIB/core/render/srt.py" cues.json out/<name>.srt  # cues = [{t0,t1,text}]
```

- Полный рендер 75–80 с ролика: около 3–3.5 минут на 3 потоках CPU (1906 кадров за 198 с), а с three.js без GPU — дольше. Запускай в фоне с логом и жди `EXIT 0` в последней строке. Не запускай два рендера одновременно.
- `mix.wav` делай длиной `DUR + 8` с: `mux.sh` обрезает звук по видео, а с запасом не страдает двухпроходная нормализация громкости.
- Зерно (`grain`) для векторных и голографических стилей ставь `0`, иначе файл раздувается.
- `cues.json` — это экспорт `CUES` из `film.js` в формат `[{t0, t1, text}]`.

## Проверка стоп-кадров (до полного рендера)

1. Сними 10–17 кадров по всему ролику: середина каждой сцены, каждый лок, каждая карточка, финал.
2. Собери лист с рамкой (`safe_sheet.py`) и посмотри на него. Если что-то спорное, открой отдельный кадр в полном размере.
3. Ищи:
   - текст, рамки или выноски за красной рамкой;
   - подписи, которые налезают друг на друга, на кривую графика, на карточку или на субтитр;
   - пустые карточки (значение ещё не появилось, а голос его уже назвал);
   - числа, которые «вспыхнули» на долю секунды и пропали (карточка должна держаться ≥ 2.5 с после лока);
   - предмет меньше трети высоты кадра в ключевой момент;
   - кадр, на котором не нарисовано то, что звучит (проверка паузой).
4. Исправь всё сразу, затем перерендери те же моменты с новым префиксом и снова посмотри лист.

Приёмы, которые уже понадобились:
- Подпись справа налезает на что-то — выровняй её по правому краю слева от точки (`anchor 'midR'`: `x -= ширина`).
- Два ярлыка рамок захвата на соседних деталях налезают — убери встроенный `tag` у `targetBox` и поставь выноски с линией в разные стороны: одну вверх-вправо, другую вниз-влево.
- Схема выходит за край — сожми её геометрию (петлю рециркуляции) или отодвинь камеру на 5–10 %, а не сдвигай текст.
- Подпись графика мешает плашке значения — перенеси подпись в пустой угол графика (над кривой слева-сверху), а плашку значения поставь сбоку от точки с короткой линией-указателем.

## Финальная проверка (после сборки)

```sh
sh <workspace>/.agents/skills/reel-render-qa/scripts/qa.sh "$P" "$P/out/<name>.mp4" 2 9 20 25 34 40 50 56 61 65 70 74
```

Скрипт проверяет:
- `blackdetect` — вывод должен быть пустым;
- громкость −14 LUFS (±0.5);
- лист кадров из готового файла с рамкой;
- распознавание речи финального звука.

Если распознавание пропустило больше 10 секунд, перепроверь это место через `reel-voice/scripts/asr_crop.py`.

## Выдача

```sh
sh <workspace>/.agents/skills/reel-render-qa/scripts/deliver.sh "$P" <name> <время_постера> ./deliverables
```

Скрипт кладёт в папку мастер, лёгкую копию (если мастер больше 15 МБ), `.srt`, постер и credits. Для постера бери кадр с предметом и главной цифрой: секунды 8–10, а не титр.

Отчёт пользователю: пути к файлам, длина, размер, громкость, что видно по частям, оговорки по фактам и то, что стоит посмотреть самому. Время — по Алматы (UTC+5).
