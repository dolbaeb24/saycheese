# Стиль three-table (Дирихле, Shazam)

Образцы: `templates/three-table-dirichlet` (ящики 0…500 000, фигурки, принцип Дирихле) и `templates/three-table-shazam` (спектрограмма из столбиков, карта звёзд, пары-ключи, совпадения в одну линию). Вся сцена лежит в одном `index.html`. three.js импортируется по абсолютному URL `/node_modules/three/build/three.module.js`, его отдаёт сервер рендера библиотеки; файлы проекта доступны по адресу `/@film/…` (например, `/@film/fonts/Manrope.ttf`).

## Инварианты

- **Сцена.** Почти чёрный тёплый фон `#090807`, экспоненциальный туман того же цвета (`FogExp2(0x090807, 0.035)`), матовый пол `MeshStandardMaterial({color: 0x14110e, roughness: 0.94})`.
- **Свет.** Тёплый ключевой `DirectionalLight(0xffe2b0, 2.3)`, слабый холодный контровой `0x8aa0c8`, мягкий заполняющий `AmbientLight(0xfff2dd, 0.58)`. Точечный оранжевый `PointLight(0xffa030)` включается на ключевом моменте (ящик загорается).
- **Предметы** простые и объёмные, светлые матовые (`0xe7e1d4`). Предмет, который «стал правдой», получает тёплое свечение (`emissive 0xff9a1f`).
- **Подписи на предметах.** Числа и слова рисуются в `CanvasTexture` шрифтом Manrope и кладутся на грань предмета (номер на ящике, «ДВОЕ» на ящике).
- **Текст кадра.** Две строки HTML поверх canvas: верхняя — тезис или число, нижняя — фраза. Одно слово в `<em>` окрашено акцентом `#ffb020`. Шрифт Manrope 700–760, `text-wrap: balance`.
- **Камера.** Вплотную к предмету, затем отъезд, когда предмет «вырастает» (ряд ящиков удлиняется, город из ящиков). Обязательны минимум 4 разных движения.
- 30 кадров/с (`--fps 30` в `video.mjs` и `mux.sh`).

## Обязательная правка под безопасную зону

Образцы сделаны **до** правила безопасной зоны: в них подписи стоят на `top: 88px` и `bottom: 120px`. В новом ролике ставь:

```css
.cap{position:fixed;left:90px;right:170px;...}   /* справа колонка иконок */
#top{top:260px; ...}
#bot{bottom:480px; ...}                          /* низ плашки ≤ y 1440 */
```

Предмет держи в полосе y 400–1300, камеру настрой так, чтобы он не уходил под иконки справа. Проверяй это листом кадров с рамкой.

## Структура index.html

```
<style> .cap, #top, #bot, em </style>
<div id=top>, <div id=bot>
<script type=module>
  import * as THREE from '/node_modules/three/build/three.module.js'
  const DUR = ...; LINES = [{t0, t1, top, bot}]   // текст кадра по времени (из таймингов слов)
  renderer (antialias, pixelRatio 1, SRGB, clearColor 0x090807), scene, fog, camera (fov 36), свет, пол
  фабрики предметов: ящик с номером (CanvasTexture), фигурка-пешка, столбик, звезда, телефон
  function render(t) { выставить позиции, свет и камеру по t; обновить #top и #bot; renderer.render() }
  new FontFace('Manrope', 'url(/@film/fonts/Manrope.ttf)').load() → document.fonts.add →
    события mark(t, 'tap'|'ping'|'whoosh'|'tick'|'land') → window.EV, DUR, render, READY = true
</script>
```

Сцена рассчитывается **от t заново** на каждом кадре: позиции падающих фигурок задаются формулой от времени (падение — `ease` плюс отскок), а не симуляцией с накоплением.

## Приёмы

- **Падение в занятый ящик.** Фигурка летит по дуге, приземляется с отскоком; ящик вспыхивает (`emissiveIntensity` растёт, загорается точечный свет), звучит событие `land` или `thump`.
- **Масштаб.** Ряд ящиков 0, 1, 2, …, «…», 500 000: камера отъезжает, последний ящик золотой, подпись «500 001 вариант».
- **Данные как предметы.** Спектрограмма — сетка столбиков (высота = громкость), шум — мелкие серые столбики, пики — светлые со свечением; затем столбики уходят, а остаются «звёзды».
- **Совпадение.** Точки-совпадения на диаграмме «время в записи / время в песне»: у случайных песен разбросаны, у нужной ложатся на диагональ, и диагональ загорается.

## Звук

Тихая подложка (`bed`), `thump` на приземлениях (`land`), `click`/`clack` на появлении (`tap`, `tick`), `ding` на находке (`ping`), `whoosh` на движении камеры (функции из `$LIB/core/audio/sfx.py`). Образец — `mix.py` в шаблонах.
