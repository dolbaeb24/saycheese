# Стиль hologram-hud

Образцы: `templates/hologram-hud-defog` (машина, график точки росы, разрез климатического блока; самый полный) и `templates/hologram-hud-microwave` (микроволновка, молекула воды, волны). Подробный справочник по API — `references/api.md`.

## Инварианты стиля

- Предмет всегда **каркас из света** над круглой подставкой-проектором на почти чёрной сцене. Это не рендер предмета.
- Три слоя глубины: фоновая точечная сетка, предмет с подставкой и передний HUD (уголки, строка статуса).
- **Одна холодная гамма** (`HUE`: 190–200 — ледяной голубой) и **один тёплый акцент** (`ACC`: около 32 — оранжевый). Акцент тратится только на число в момент, когда оно «стало правдой». Больше ничего им не красится.
- Белый — это «горячее»: фронт сканирования, вспышка детали на 3 кадра при захвате.
- **Текст никогда не лежит на каркасе**: у каждого текста своя тёмная плашка с рамкой в 1 px.
- Переходы внутри стиля: линия сканирования проявляет предмет (`scan`) или стирает его (`scanDown`), лупа раскрывается как iris. Никаких затемнений и склеек внутри сцены.
- Движение на каждом кадре при 24 кадрах/с. Захват рамкой: большая рамка повёрнута на 45°, сжимается до детали за 0.2 с и вспыхивает на слове.

## Шрифты (важно для русского)

Оригинальные Rajdhani и Share Tech Mono **не содержат кириллицы**. В проекте используются Exo 2 (интерфейс, 100–900) и JetBrains Mono (цифры, 100–800), оба под OFL. Они лежат в `fonts/` образца и подключаются через `fonts/fonts.css`. В `engine/hud.js` проекта уже стоят правки под вертикальный кадр (библиотечный оригинал не трогать):

- `FONT = { ui: 'Exo2', mono: 'JBMono' }`;
- строка статуса 24 px; ярлык рамки 26 px на полосе 34 px;
- субтитр 44 px, межстрочный 54, сдвиг +22 px вправо.

## Структура проекта

```
index.html   canvas 1080×1920, fonts.css, <script type=module src=main.js>
main.js      ждёт document.fonts.load(Exo2 300-700, JBMono 400) → film = makeFilm() → DUR, EV, CUES, render, READY

models.js    модели в единицах сцены (Model из models/mkmodel.mjs → prepModel(m.toJSON())), именованные точки для выносок
engine/      holo.js (каркас, проекция, scan, explode, solid, pad, scan plane), hud.js (тема, плашки, рамки, карточки, чипы, субтитры)
```

## Как строить ролик

1. **Модель.** Каждая деталь, о которой говорит голос, — отдельный `part` (рамка захватывает `info.bbox[partId]`), а движущиеся детали — отдельные `piece` с осью (`axis: {c, d}`), чтобы их можно было вращать (`angle: {pieceId: рад}`): заслонка, крыльчатка вентилятора, тарелка. Делай узнаваемый силуэт, а не набор одинаковых коробок. Экспортируй именованные точки (`CAR.head`, `HV.evap`, `wsPoint(u, v)`) для выносок и частиц.
2. **Камеры.** `C({target, yaw, pitch, dist, cx: 500, cy})`, переходы — `mixCam(A, B, easing(seg(t, t0, t1)))`. `cx = 500` (чуть левее центра из-за колонки иконок справа), `cy` 900–1000, чтобы предмет был между карточками и субтитрами. При `yaw ≈ π` камера смотрит со стороны −z.
3. **Сцена — функция от t.** `holo.draw(ctx, model, cam, {...})` возвращает `{bbox, project}`. Через `project` любая 3D-точка переводится в экран: этим пользуются выноски, частицы, капли, потоки. Экранные координаты руками не пиши.
4. **Информация на времени слова** `K.<слово>`:
   - рамка: `U.targetBox(ctx, T, info.bbox.part, seg(t, K.x - 0.22, K.x), {flash: flashAt(t, K.x), tag, pad})`;
   - карточка: `specCard` — появление (`reveal`) за 0.3–1.5 с до слова, прокрутка (`roll`) от появления до слова, лок на слове плюс событие `confirm`;
   - живой счётчик (температура растёт): `roll: 0.999`, пока значение меняется, и `1` в момент лока — тогда цифры в основном цвете, а в акцент переходят только при локе;
   - выноска к точке: линия от точки, точка-якорь и плашка `labelPlate`, прижатая к безопасной зоне.
5. **Раскладка вертикального кадра.** Карточки: `x 100, y 290`, ширина 520–640. Чипы-итоги: две колонки, `x 100/520`, `w 340`, `y 290/410`. Субтитр: `y 1428, maxW 740, x 488`. HUD-уголки — по безопасному прямоугольнику, строка статуса — на `y 248`.
6. **Финал.** Чипы-итоги по одному на действие → `scanDown` стирает предмет → титульная плашка с вопросом-хуком и ответом акцентом.

## Приёмы, которые уже работают (смотри код образцов)

- Туман на стекле: 1700 детерминированных капель `hash(i)` в координатах стекла (u, v) плюс молочный слой; очищение снизу вверх по фронту `clearFront(t)`.
- График в плашке: оси, сетка, кривая рисуется по `seg`, точка ползёт по графику, пунктиры к значениям, лок значения с плашкой сбоку.
- Лупа (кадр в кадре): круг с клипом, линия от точки на предмете, внутри — молекулы и капли на стекле в крупном масштабе.
- Разрез агрегата в плоскости xy: поток частиц по ломаной (`polyLen`, `along`), у каждой частицы метка состояния (влажная, сухая, тёплая), пунктирная петля рециркуляции, капли по дренажу.
- Деталь, которая «греется» или должна выделиться: `keep: {pieceId: '#ffffff'}`. Заливка работает только при `solid > 0`, поэтому такую деталь рисуют вторым проходом с `only: [partId]` и `solid: 1`.

## Подводные камни

- Две выноски на соседних деталях налезают друг на друга. Убери встроенный `tag` и разведи выноски в разные стороны: одну вверх-вправо, другую вниз-влево.
- Рамка захвата раздувается на длинной детали. Захватывай только корпус детали и уменьши `pad`.
- Волновые «пакеты» и частицы залезают на карточки. Рисуй их только в своей области или ограничь `clip`.
- Подпись кривой графика мешает плашке значения. Разнеси их по разным углам графика.
- Цифры дёргаются при прокрутке. Цифры моноширинные (JBMono), а прокрутка идёт справа налево.
