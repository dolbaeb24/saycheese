# Звук и сведение

Образец — `templates/hologram-hud-defog/mix.py`: в нём есть все приёмы ниже. Новый ролик начинай с его копии и меняй три вещи: аккорды подложки, словарь событий и непрерывный шум.

## Структура mix.py

```
events.json (из events.mjs) ──► dur, ev
4 стерео-шины (N, 2), N = (DUR + 8) * 48000:
  mus  — подложка: 4 аккорда по 4 с, синусы с лёгкой расстройкой ±0.15 %, ФНЧ 2.4 кГц, мягкое арпеджио на 16-х
  fol  — звуки событий: lock, roll, confirm, scan, whoosh, ...
  amb  — непрерывный фон: шум комнаты (brown, ФНЧ 500 Гц), гул или вентилятор между событиями-включателями
  vox  — голос: voice/<id>.wav, ресемпл до 48 кГц, старт VO = 0.30 с, gain 1.4
приглушение: огибающая голоса (порог 0.01, max-фильтр 0.5 с, сглаживание 0.2 с)
  mus *= 1 - 0.8 * env;  amb *= 1 - 0.35 * env;  fol *= 1 - 0.7 * env, кроме 0.2 с после lock/confirm/warn
mix = mus + fol + amb + vox ──► limit(0.95) ──► mix.wav (float32) ──► mux.sh нормализует до -14 LUFS
```

Функции берутся из `$LIB/core/audio/sfx.py`: `SR=48000, t_, env_exp, bp, lp, hp, noise, norm, brown, add(buf, x, t, gain, pan), limit, compress`. `add` пишет в **стерео** буфер `(N, 2)`: моно-буфер вызовет ошибку.

## Словарь событий (EV)

| `k` | Звук | Громкость |
|---|---|---|
| `scan` / `scanDown` | свип-шум 250→5000 Гц плюс восходящий или нисходящий тон, длина `d` | 0.5 / 0.42 |
| `lock` | удар 95→42 Гц, щелчок, металлический призвук, два тона-блипа | 0.8 |
| `roll` | тики с частотой кадров на время `d` (прокрутка цифр) | 0.15 |
| `confirm` | трезвучие из блипов с вибрато (значение зафиксировано) | 0.3·v |
| `tick` | двухнотный блип (чип встал на место) | 0.25 |
| `whoosh` | полосовой свип по шуму | 0.32 |
| `iris` | высокий шум плюс восходящий zip (открылась лупа) | 0.35 |
| `servo` | пилообразный сервопривод с подъёмом тона (заслонка, механизм) | 0.2 |
| `zip` | короткий восходящий тон | 0.25 |
| `drops` / `drip` | россыпь плинков (капли) / одиночная капля с падением тона | 0.22 / 0.35 |
| `breath` | полосовой шум 0.5–2.6 кГц с мягкой огибающей (выдох) | 0.22 |
| `warm` | низкий шум плюс 110/165 Гц (нагрев) | 0.3 |
| `fog` / `clear` | мерцание высоких синусов, нарастает / убывает (запотевание / очистка) | 0.06 / 0.12 |
| `warn` | два прямоугольных тона A→F (предупреждение) | 0.3 |
| `slide` | скользящий тон 520→300 Гц (точка ползёт по графику) | 0.16 |
| `fanOn` / `fanMax` / `fanOff` | включают непрерывный шум вентилятора, удваивают его, выключают | фон 0.045 |
| `humOn` / `humOff` | гул 100/200/300 Гц с модуляцией 50 Гц (магнетрон, трансформатор) | фон 0.10 |
| `ding` | колокольчик 1568 Гц с обертонами (финальный «готово») | 0.55 |

Каждое видимое действие на экране должно иметь событие в `EV` с точным временем. Время берётся из того же объекта `K`, что и анимация, поэтому звук и картинка не расходятся.

## Правила

- Подложка — в тональности, подходящей теме (холод: ми минор `[52,59,64,67] [48,55,60,64] [50,57,62,66] [47,54,59,62]`; техника: ре минор). Без «пианино со струнными». Ноты подложки не ниже MIDI 48, иначе низ гудит на телефоне.
- Голос примерно на 10 дБ громче музыки. Приглушение держится между словами и не «качает».
- Минимум одна настоящая пауза (0.3–0.5 с почти тишины) перед главным поворотом.
- Фон затухает за 1.5 с до конца, музыка — за 2.5 с.
- Пиковое значение после `limit` должно быть ≤ 0.95. Итоговую громкость делает `mux.sh`, сам не нормализуй.
